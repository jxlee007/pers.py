    IDENTITY = id
    - AUTO_INCREMENT in SQL, 
    a feature that automatically generates unique integer IDs for database rows.
    Key points:
        - IDs are typically integers that increase with each new row
        - The `AUTO_INCREMENT` keyword automatically assigns the next sequential value
        - You don't need to manually specify an ID when inserting new rows—the database handles it automatically

        It's a convenient way to ensure each record has a unique identifier without extra effort.

    eg 
        CREATE TABLE Customers (
            id int NOT NULL AUTO_INCREMENT,
            firstname varchar(255),
            lastname varchar(255)
        );

        CREATE TABLE Products (
            number int AUTO_INCREMENT
        );

        CREATE TABLE table_name(
            column_name int NOT NULL AUTO_INCREMENT
        )
    
    -  Now when inserting a new row, 
    we do not need to specify the value of the id column, 
    as it will automatically be set. 

    eg
        INSERT INTO Customers (firstname, lastname, city, age)
        VALUES 
        ('demo', 'demo', 'Paris', 52),
        ('test', 'test', 'London', 21);  

        SELECT * FROM Customers;

    - By default, the AUTO_INCREMENT column starts with the value 1. 
    This can be changed if needed, using the following:

    eg 
        ALTER TABLE Customers
            AUTO_INCREMENT=555

        - The UNIQUE constraint ensures that all values in a column are different.
        - A PRIMARY KEY constraint automatically has a UNIQUE constraint.

        - However, you can have many UNIQUE constraints per table, 
        but only one PRIMARY KEY constraint per table. 

        eg 
        ALTER TABLE Customers
        ADD UNIQUE (lastname)
