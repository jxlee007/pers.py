    DATA ANALYSIS
    - Raw (or untreated) data needs to be processed and analyzed so it can be used to make decisions.
    - 1. Question, 2. Collect, 3. Clean, 4. Insights, 5. Communicate

    1. Question
        - data analysis process, starting with questions on database.

        - The schema/visualization of database 
        helps us check if the question can be answered with the data.
        - schema has field names, keys, table names

        Some questions can be answered with a filtering query

    2. Collect
        - Raw data requires analysis
        - The first step in data analysis is defining your question
        - Data can come from different sources 
        - you can use different techniques to collect your data

        - Data grouping is a powerful tool when working with large datasets. 
        - Grouping allows you to collect and see data in a new way, to answer more complex questions.

        - GROUP BY allows you to organize similar data into categories. 
        - It's combined with aggregations to compute key metrics for a group of records.
        eg 4. SELECT country, COUNT(*) FROM users GROUP BY country
        
        - GROUP BY organizes data into categories
        - GROUP BY is frequently combined with aggregation

    GROUP & FILTER
        - You can combine GROUP BY with WHERE filters. 
        - Data is filtered first, then grouped and at last aggregation.
            SELECT AVG(budget) -> 3
            FROM movies
            WHERE budget > 50  -> 1
            GROUP BY genre     -> 2

        - HAVING allows you to filter data that has been grouped.
        - if we need to group first, then filter
            SELECT class, AVG(score) -> 3
            FROM students
            GROUP BY class           -> 1
            HAVING AVG(score) > 85;  -> 2

        - You can combine WHERE with GROUP BY to filter data first, then group
        - You can use HAVING to group data first, then filter


    3. Clean
        - use to fix errors in the data that has been collected

        - Duplicated data is a very common issue. It refers to additional copies of the same data.
        - use GROUP BY in combination with HAVING to check for duplicates

        eg SELECT title , COUNT(title)  FROM movies  GROUP BY title     HAVING COUNT(tit1e) > 1;
           SELECT id, title             FROM movies  GROUP BY id, title HAVING COUNT(id) > 1

        - You can group data by multiple fields separating them with a comma. 
        - You can use this to check for duplicates in multiple fields at once
        
        - Use DISTINCT to eliminate duplicate values
        SELECT DISTINCT genre FROM novies

        - Another issue is missing data
        - NULL is used to indicate that a data value is missing and does not exist in the database
        SELECT * FROM movies WHERE genre IS NULL

        - Data quality issues can affect the accuracy of your data analysis
        - You can use DISTINCT to fix data duplication
        - NULL stands for missing data values

        fix data type

        eg SELECT  id, title, is_oscar_winner FROM movies WHERE is_oscar_winner = False;

        - Data values can be classified into different data types
        - The boolean data type has two possible values: True or False
