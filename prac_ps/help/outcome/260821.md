We have discussed three fundamental types of mathematical patterns that you will constantly use to practice mathematical induction.
Induction is the exact tool used to prove that the formulas for these patterns work for any day $n$. Here is a quick recap of the three structures we broke down:
------------------------------
## 📈 1. Linear Patterns (Arithmetic Sequences)

* The Rule: You add or subtract the exact same number at every step.
* The Gaps: Constant single difference (e.g., $+2, +2, +2$).
* Example sequence: $2, 4, 6, 8, 10$.
* Induction target: Proving simple summation formulas like $2 + 4 + 6 + ... + 2n = n(n+1)$.

## 📐 2. Quadratic Patterns (Triangular Numbers)

* The Rule: You add an increasing amount each step, but that amount grows at a steady rate.
* The Gaps: Constant second difference (e.g., adding $+2, +3, +4$, where the gap increases by $+1$ each time).
* Example sequence: $1, 3, 6, 10$ (Your StackCoins problem).
* Induction target: Proving the classic triangular sum formula: $1 + 2 + 3 + ... + n = \frac{n(n+1)}{2}$.

## 🚀 3. Exponential Patterns (Geometric Sequences)

* The Rule: You multiply by a fixed scale factor at every single step.
* The Gaps: Explosive growth driven by constant scaling (e.g., $\times 2, \times 2, \times 2$).
* Example sequence: $1, 2, 4, 8$ (Your CacheCoins problem).
* Induction target: Proving power-based formulas like $1 + 2 + 4 + ... + 2^{n-1} = 2^n - 1$.
